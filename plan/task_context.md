## Зависимости и конфигурация

### Docker
- Контейнер запущен с монтированной директорией (dev mode)
- Используется `uv` для управления зависимостями
- Порт: 8000 (по умолчанию)

### Python окружение
- Python 3.11
- FastAPI для API
- Pydantic для валидации
- pytest для тестирования

### Переменные окружения
- `OPENROUTER_API_KEY` - для LLM
- `RAG_SERVICE_URL` - для RAG (опционально)
- Другие настройки из `.env_example`

## Важные замечания

1. **Docker контейнер** работает с монтированной директорией, поэтому изменения в коде сразу доступны
2. **Тесты** должны запускаться внутри контейнера для корректной работы
3. **API endpoints** могут потребовать обновления в `app.py` для полной интеграции
4. **Состояние квиза** хранится в памяти контейнера (не персистентное)

## Команды для работы

### Запуск контейнера:
```bash
cd agent_service && docker-compose -f docker-compose-dev.yml up -d
```

### Просмотр логов:
```bash
docker logs -f agent_service-dev
```

### Запуск тестов:
```bash
docker exec agent_service-dev uv run pytest agent_service/tests/test_interactive_quiz.py -v
```

### Вход в контейнер:
```bash
docker exec -it agent_service-dev /bin/bash
```

### Синхронизация зависимостей (после изменений в pyproject.toml):
```bash
docker exec agent_service-dev uv sync
docker restart agent_service-dev
```
