# Этап 1: Shared Retrieval Subgraph (Базовый слой знаний)

## Цель
Реализовать унифицированный подграф поиска (`Shared Retrieval Subgraph`), который будет служить источником знаний для всех остальных режимов (Chat, Quiz, Algo). Он должен уметь маршрутизировать запросы к различным инструментам (RAG, Tavily, Context7), агрегировать результаты и синтезировать "Golden Source" ответ.

## Задачи

### 1. Подготовка инфраструктуры
- [ ] Создать структуру пакета: `agent_service/graphs/`
- [ ] Создать базовые файлы:
    - `agent_service/graphs/__init__.py`
    - `agent_service/graphs/retrieval.py`
- [ ] Перенести типы состояния (`AgentState` и специфичные для Retrieval) в `agent_service/state.py` (или аналогичный общий модуль).

### 2. Реализация узлов (Nodes)
- [ ] **Router Node**:
    - Анализирует запрос пользователя.
    - Определяет необходимые источники: `rag` (база знаний), `web` (Tavily), `docs` (Context7).
    - Может выбрать несколько источников одновременно.
- [ ] **Retrieval Nodes**:
    - `rag_node`: Вызов `rag_search_async`.
    - `tavily_node`: Вызов Tavily Search (нужно добавить инструмент в `langchain_tools.py` или использовать MCP).
    - `context7_node`: Вызов Context7 (нужно добавить инструмент).
- [ ] **Aggregator Node**:
    - Собирает результаты от всех запущенных узлов поиска.
    - Унифицирует формат документов.
- [ ] **Prepare Material Node**:
    - Синтезирует единый Markdown-ответ из найденных фрагментов.
    - Удаляет дубликаты, исправляет форматирование.

### 3. Сборка графа
- [ ] Определить `StateGraph` для Retrieval.
- [ ] Настроить условные переходы от Router к инструментам.
- [ ] Настроить сбор результатов в Aggregator.
- [ ] Финализировать в Prepare Material.

### 4. Тестирование
- [ ] Создать тест сценария: `agent_service/tests/scenarios/test_retrieval_graph.py`.
- [ ] Проверить сценарии:
    - Только RAG (фундаментальный вопрос).
    - Только Web (новости/тренды).
    - Смешанный поиск.
    - Отсутствие результатов (Fallback).

## Ожидаемый результат
Модуль `retrieval.py`, экспортирующий скомпилированный граф `retrieval_graph`, который принимает запрос и возвращает `prepared_material` и список `documents`.
