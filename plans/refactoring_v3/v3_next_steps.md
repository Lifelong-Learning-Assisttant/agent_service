# План развития и стабилизации NetRunner V3 (Следующие шаги)

## Контекст
Архитектура V3 успешно внедрена: графы разделены на подграфы (`Supervisor`, `Chat`, `Quiz`, `Retrieval`), инструменты вынесены в пакет `tools/`, исправлены основные ошибки типизации. Начато внедрение Rich UI событий (метаданные для квизов).

## Задача 1: Полное покрытие интеграционными тестами
Необходимо убедиться, что все возможные переходы в графах работают корректно.

### Сценарии для реализации:
1.  **Quiz Edge Cases**:
    -   Прерывание квиза командой `/finish_quizz` на середине.
    -   Пропуск всех вопросов через `/skip_question`.
    -   Обработка некорректных ответов (невалидный JSON в `/answer`).
    -   Сценарий "Вопрос по вопросу" (RAG уточнение во время активного квиза) и возврат контекста.
2.  **Retrieval Deep Dive**:
    -   Поиск только по документации (`Context7`).
    -   Поиск только в вебе (`Tavily`).
    -   Смешанный поиск и корректная работа `aggregator_node`.
3.  **Supervisor Routing**:
    -   Переход из режима квиза в режим помощи по алгоритмам (через заглушку).
    -   Корректный сброс состояния при завершении сессии.

## Задача 2: Обновление Frontend (React)
Адаптация интерфейса "Нетраннерской Деки" под новые возможности агента.

### Задачи:
1.  **Компонент Quiz**:
    -   Реализовать рендеринг кнопок выбора на основе `meta.options` из события `quizz_question`.
    -   Добавить поддержку `multiple_choice` (чекбоксы).
    -   Реализовать отправку команды `/answer [indices]` при клике.
2.  **Улучшение UX**:
    -   Отображение хода мыслей (`thought` / `reasoning`) в HUD-стиле.
    -   Интерактивные карточки источников (Sources) на основе метаданных.
    -   Визуальная индикация активного режима (`interaction_mode`).
