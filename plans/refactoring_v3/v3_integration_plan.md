# План интеграции архитектуры Agent V3 с Web UI и написания тестов

## Цель
Обеспечить полную интеграцию новой модульной архитектуры агента (Supervisor Graph, Quiz Subgraph, RAG) с существующим веб-интерфейсом. Реализовать поддержку интерактивных элементов (кнопки выбора ответа) через расширенные события WebSocket и покрыть новые сценарии интеграционными тестами.

## Этап 1: Обновление Agent System для поддержки Rich UI событий

Необходимо обогатить события, отправляемые агентом в UI, чтобы фронтенд мог отрисовывать специализированные компоненты (например, кнопки для квизов).

### Задачи:
1.  **Модификация `create_quiz_node` в `agent_service/agent_system.py`**:
    -   При отправке события `quizz_question` (начало квиза) добавлять в поле `meta`:
        -   `options`: список вариантов ответов (если есть).
        -   `type`: тип вопроса (`single_choice`, `multiple_choice`, `open_ended`).
        -   `question_index`: индекс текущего вопроса.
        -   `total_questions`: общее количество вопросов.

2.  **Модификация `process_quiz_answer_node` в `agent_service/agent_system.py`**:
    -   Аналогично добавить метаданные (`options`, `type`, индексация) при переходе к следующему вопросу квиза.

3.  **Валидация маркеров**:
    -   Убедиться, что системные маркеры `[SYSTEM: QUIZ_STARTED]` и `[SYSTEM: NEXT_QUESTION]` корректно добавляются в текстовый ответ для обратной совместимости или специальной обработки на клиенте.

## Этап 2: Создание интеграционных тестов V3 (Сценарий Квиза)

Написание тестов, эмулирующих реальное взаимодействие пользователя с новой архитектурой квизов.

### Задачи:
1.  **Создать `agent_service/tests/scenarios/test_v3_integration_quiz.py`**:
    -   Тест-кейс: Генерация и прохождение квиза.
    -   Проверки:
        -   Инициализация сессии.
        -   Запрос "Создай тест по Python".
        -   Получение события `quizz_question` и валидация наличия `options` в `meta`.
        -   Отправка ответов (эмуляция выбора пользователя).
        -   Проверка перехода к следующему вопросу.
        -   Получение финальной оценки (`grade_done`) и отчета.
