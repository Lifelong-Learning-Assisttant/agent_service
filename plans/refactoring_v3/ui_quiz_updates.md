# Доработки Web UI для Quiz Subgraph v3.5

## Цель
Адаптировать интерфейс «Нетраннерской Деки» под детерминированный роутинг и гибридную систему оценки, реализованную в Агенте v3.5.

## 1. Компонент выбора ответов (MCQ)
- [ ] **Рендеринг вариантов**: При получении сообщения типа `quizz_question` с метаданными `options`, отображать их в виде кликабельных кнопок/карточек под текстом вопроса.
- [ ] **Множественный выбор**: Поддерживать состояние выбора нескольких вариантов (checkbox style) для вопросов типа `multiple_choice`.
- [ ] **Кнопка подтверждения**: Добавить кнопку «Отправить ответ», которая формирует команду в формате `/answer [indices]` (например, `/answer [0, 2]`).
- [ ] **Блокировка после отправки**: Деактивировать кнопки выбора после того, как ответ был отправлен, до получения следующего вопроса.

## 2. Режимы Деки (Interaction Modes)
- [ ] **Авто-переключение**: При входе в режим квиза автоматически активировать вкладку `ANSWER_QUIZ`.
- [ ] **Визуальная индикация**: Подсвечивать вкладку `ANSWER_QUIZ` неоновым цветом при ожидании ответа на вопрос.
- [ ] **Разделение потоков**:
    - Ввод во вкладке `ANSWER_QUIZ` отправляется как ответ на вопрос.
    - Ввод во вкладке `AI_SYNC` отправляется как уточняющий вопрос (активирует RAG-подсказку).

## 3. Обратная связь и Пояснения
- [ ] **Мгновенный результат**: При получении ответа от `explainer_node`, отображать его с соответствующей иконкой (✅/❌) и стилизацией (Lime/Red).
- [ ] **История квиза**: Добавить в боковую панель или лог чата мини-карточки с историей пройденных вопросов и оценками (traceability).

## 4. Команды управления
- [ ] **Быстрые действия**: Добавить в интерфейс Деки (рядом с полем ввода) кнопки-иконки для команд:
    - `⏭ Пропустить` (`/skip_question`)
    - `🏁 Завершить` (`/finish_quizz`)

## Технические детали
- **Формат обмена**: Использовать поле `meta` в WebSocket-событиях для передачи списка `options` и `question_type`.
- **Стейт-менеджмент**: Обновить Zustand-стор для хранения текущего выбранного индекса во время квиза.
