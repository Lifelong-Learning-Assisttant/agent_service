# Этап 3: Quiz Subgraph (Режим обучения)

## Цель
Реализовать подграф для проведения квизов (`Quiz Subgraph`). Поддерживать роли Интервьюера и Ментора, циклическую логику вопросов и возможность прерывания/пропуска.

## Задачи

### 1. Реализация узлов (Nodes)
- [ ] **Quiz Router Node**:
    - Внутренний маршрутизатор подграфа.
    - Определяет действия: `answer` (ответ), `skip` (пропуск), `help` (подсказка), `stop` (завершение).
- [ ] **Interviewer Node**:
    - Ведет процесс квиза.
    - Принимает ответ, проверяет его (или передает на проверку), задает следующий вопрос.
    - Использует `Shared Retrieval` для генерации небольших подсказок (без раскрытия ответа).
- [ ] **Skip Node**:
    - Логика пропуска вопроса (маркировка как "не отвечен").
- [ ] **Check Progress Node**:
    - Проверяет, остались ли вопросы.
    - Если вопросы есть -> возвращает к Interviewer.
    - Если вопросы кончились -> переходит к Mentor.
- [ ] **Mentor Node**:
    - Активируется после завершения теста.
    - Генерирует развернутый фидбек по всем вопросам.
    - Отвечает на уточняющие вопросы пользователя после теста.

### 2. Управление состоянием (QuizState)
- [ ] Определить локальное состояние: `current_question_index`, `user_answers`, `quiz_questions`.
- [ ] Реализовать сохранение прогресса при выходе/возврате (Persistence).

### 3. Сборка графа
- [ ] Определить `StateGraph` для Quiz.
- [ ] Настроить цикл: `Interviewer` -> `Check Progress` -> `Interviewer`.
- [ ] Настроить выход: `Check Progress` -> `Mentor` -> `End`.

### 4. Тестирование
- [ ] Создать тест сценария: `agent_service/tests/scenarios/test_quiz_graph.py`.
- [ ] Проверить сценарии:
    - Прохождение квиза от начала до конца.
    - Использование `/skip_question`.
    - Запрос подсказки.
    - Получение финального фидбека.

## Ожидаемый результат
Модуль `quiz.py`, экспортирующий `quiz_graph`.
