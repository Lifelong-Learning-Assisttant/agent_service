# Этап 4: Algo Subgraph (Режим кода)

## Цель
Реализовать подграф для решения алгоритмических задач (`Algo Subgraph`). Обеспечить взаимодействие с Code Sandbox (или его эмуляцией), проверку решений и менторство.

## Задачи

### 1. Реализация узлов (Nodes)
- [ ] **Algo Router Node**:
    - Определяет интент: `submit` (сдача кода), `help` (подсказка), `stop` (завершение).
- [ ] **Algo Interviewer Node**:
    - Ведет процесс.
    - Принимает код, отправляет в Sandbox.
    - Анализирует результаты тестов и сообщает их пользователю.
    - Не дает готовых решений, только направляет.
- [ ] **Sandbox Node**:
    - Выполняет код пользователя (через инструмент `tool_exec` или мок).
    - Возвращает stdout, stderr и статус тестов.
- [ ] **Algo Mentor Node**:
    - Активируется после успешной сдачи или сдачи.
    - Проводит Code Review, указывает на неоптимальные места (Big O).

### 2. Интеграция с инструментами
- [ ] Убедиться, что `get_algo_problem_info` и `get_algo_solution` доступны и работают асинхронно.
- [ ] Реализовать или заглушить `code_sandbox_exec` (безопасное исполнение).

### 3. Сборка графа
- [ ] Определить `StateGraph` для Algo.
- [ ] Настроить цикл: `Interviewer` -> `Sandbox` -> `Interviewer`.
- [ ] Настроить выход: `Interviewer` -> `Mentor` -> `End`.

### 4. Тестирование
- [ ] Создать тест сценария: `agent_service/tests/scenarios/test_algo_graph.py`.
- [ ] Проверить сценарии:
    - Отправка правильного решения.
    - Отправка решения с ошибкой (SyntaxError / LogicError).
    - Запрос подсказки по условию.

## Ожидаемый результат
Модуль `algo.py`, экспортирующий `algo_graph`.
